Zone Server API

Zone-based multi-vendor commerce backend — Express.js + MongoDB + Vercel.

Version 1.0.0
Base /api/v1
Auth Bearer JWT
Format JSON
Base URLhttps://your-project.vercel.app/api/v1

🔐 Authentication

Protected routes require a Bearer token in the Authorization header.

Authorization: Bearer <your_jwt_token>
🔓 Public: GET stores, store detail, stores by pin code, OTP login, OTP verify.

📦 Response Format

Success

{ "success": true, "message": "OK", "data": {}, "meta": {} }

Error

{ "success": false, "message": "Request failed", "error": { "reason": "NOT_FOUND", "message": "No record found" } }

Pagination Meta

{ "meta": { "page": 1, "limit": 10, "total": 250, "total_pages": 25 } }

⚠️ Error Codes

HTTPReasonDescription
400VALIDATION_ERRORBody or query params failed Zod validation
401INVALID_CREDENTIALSWrong username or password
401INVALID_TOKENJWT missing, invalid, or expired
401INVALID_OTPOTP does not match or has expired
404NOT_FOUNDResource does not exist or is soft-deleted
409DUPLICATE_ENTRYUnique constraint violation (email, SKU, username)
500INTERNAL_ERRORUnexpected server error
